# EnviroLens Training Outline

## Audience

Epidemiologists, data managers, GIS analysts, and policy officers new to the platform.

## Modules

1. **Orientation** — platform purpose, Verdania use case, privacy rules
2. **Metadata catalogue** — finding datasets, stewards, sensitivity
3. **Data quality** — reading scores and issues; correcting source data
4. **Risk index** — AP-EHRI components, weights, limitations
5. **API basics** — `/docs`, authentication header, common GET endpoints
6. **Dashboards** — Power BI pages and filters
7. **Maps** — QGIS project and exported PNGs
8. **Reporting** — Quarto technical vs policy brief
